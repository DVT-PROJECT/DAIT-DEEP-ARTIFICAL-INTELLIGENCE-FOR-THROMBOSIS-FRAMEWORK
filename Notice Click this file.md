# UPLOADED MATERIAL

## 1. DAIT

This folder contains the complete DAIT Framework project. However, the `model.keras` file is not included because its file size exceeds GitHub's file size limit.

You can train the model using the specific dataset mentioned below:

**Kaggle Dataset:**  
https://www.kaggle.com/datasets/abdullahmohsinune/thrombus-vs-non-thrombus-dataset-images

This dataset was collected as part of a **European Union-funded project**. A detailed description of the dataset, its background, and its analysis is available on the Kaggle dataset page.

The purpose of this repository is to provide access to the **preprocessed dataset structure, framework, functional prototype, and supporting materials**. For the complete dataset description and background information, please refer to the Kaggle page.

The Kaggle dataset contains the following folders and files:

- `BALANCED_DATASET`
- `DATA`
- `SPLIT`
- `ml_data`
- Training CSV file
- Testing CSV file

The main folders used for machine learning preprocessing and experimentation include:

- `ml_data`
- `BALANCED_DATASET`
- `SPLIT`

### Dataset Background

The original dataset contains approximately **337,703 JPG images**. The source data was originally available in video format, where the videos were stored in DICOM (`.dcm`) format and converted to MP4 for frame extraction.

The video frames were extracted to create image data. Because the original dataset contained significant class imbalance and variation, augmentation and preprocessing techniques were applied to create the `BALANCED_DATASET`.

The dataset and preprocessing work are still under development, and further improvements may be made in the future.
